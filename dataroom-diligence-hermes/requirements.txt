# Versions are pinned because the skill is authored on one architecture and run
# on another (aarch64). Do NOT vendor wheels or commit a virtualenv into this
# directory -- build the wheelhouse on the target machine, or download
# aarch64-tagged wheels for it:
#
#   pip download -r requirements.txt \
#       --only-binary=:all: --platform manylinux2014_aarch64 \
#       --python-version 3.11 -d /path/to/wheelhouse
#
# Then, once, on the target before the skill runs:
#
#   pip install --no-index --find-links /path/to/wheelhouse -r requirements.txt
#
# The wheelhouse must also contain the transitive dependencies pip resolves
# (httpcore, h11, anyio, sniffio, certifi, idna, et-xmlfile). `pip download`
# collects them; a hand-assembled wheelhouse will not.
